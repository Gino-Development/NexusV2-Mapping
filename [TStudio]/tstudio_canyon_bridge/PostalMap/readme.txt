### Steps to Update the Postal Map for Rayton Canyon Bridge and Alamo Island Integration:

1. **Download the Postal Code Map Resource:**
   - Obtain the postal map from [this forum link](https://forum.cfx.re/t/release-postal-code-map-minimap-new-improved-v1-3/147458).

2. **Identify Your Map Configuration:**
   - **Option 1:** Using **only the Rayton Canyon Bridge**.
   - **Option 2:** Using **Rayton Canyon Bridge + Alamo Island** together.

3. **Locate the `.ytd` Files:**
   - Find the `.ytd` files provided with the Rayton Canyon Bridge and/or Alamo Island.

4. **Replace the Postal Map Files:**
   - Navigate to the `stream` folder within the Postal Code Map resource.
   - Replace the existing `.ytd` files with the `.ytd` files corresponding to your map setup:
     - If using **only Rayton Canyon Bridge**, replace with the `.ytd` file designed for that map.
     - If using **Rayton Canyon Bridge + Alamo Island**, replace with the `.ytd` file that integrates both maps.

5. **Restart or Refresh Your Server:**
   - Restart your FiveM server to apply the changes.
   - Verify that the postal map reflects the changes by checking the minimap in-game.
