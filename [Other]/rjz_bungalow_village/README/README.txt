INSTALLATION

1- drag and drop the resource "rjz_bungalow_village" to your resources folder.

2- ensure the resource   
    ensure rjz_bungalow_village

3- update your server build to 5128 or higher:    https://runtime.fivem.net/artifacts/fivem/

4- update your game build to 2189 or higher: "set sv_enforceGameBuild 2189" in your server.cfg

5- clear your server cache

6- DONE!

MORE INFORMATION

We are using the cfx team's asset escrow system, you can read more about it here: https://forum.cfx.re/t/introducing-asset-escrow-for-your-resources/4777151

The user account that owns the product must be the same one that holds the key used on the server, if not, you must transfer to the correct account by accessing: https://keymaster.fivem.net/asset-grants.
Make sure you send to the correct account as you can only do this once so be careful.

Purchases are tied to your Cfx.re account, not a specific license key.
This package will work for all of your keys.


FREQUENT PROBLEMS

**"You lack the required entitlement to use (...)"
- Basically, the account that owns the product is not the same that has the key used on the server, if you have already cleared the server's cache, you must transfer the ownership of the asset to the account that owns the key.

**If you use some FTP program to transfer files to the server, you may face problems, especially if you use FileZilla, try using WinSCP, you should succeed.

**Players who do not have the time and date synchronized can be blocked when trying to enter the server receiving a message warning that it was not possible to start the protected resource, instruct them to do the synchronization and the problem should go away.

Always remember the need to clear the server cache, often the problem is quickly resolved by doing so.


If you want to use the minimap that I make available, move the "minimap" folder to the stream folder.

I am providing a file with the coordinates of the doors, but you are responsible for any script to lock them, this package does not come with any system for this.
